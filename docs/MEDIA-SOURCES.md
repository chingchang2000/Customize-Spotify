# Built-in media sources

Customify intentionally references web-hosted media for artist presets instead of AI-generated artwork.

| Preset | Media source |
| --- | --- |
| Graduation Sky / Kanye West | GIPHY: https://giphy.com/gifs/kanye-west-bully-CwBYQ8WkQT6sGVXs7g |
| Utopia Concrete / Travis Scott | Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Travis_Scott_2023.jpg |
| Midnight Views / Drake | Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Drake_July_2016.jpg |
| DAMN. Red / Kendrick Lamar | Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Kendrick_Lamar_2013.jpg |
| Chroma Green / Tyler, The Creator | Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Tyler_The_Creator.jpg |

Customify downloads the selected image/GIF when a user applies a theme. Each external work remains subject to the license, terms, attribution requirements, and personality/publicity rights listed by its source.

Users can replace any built-in media URL with their own image or GIF in Visual Studio.
